# `hamstik project unarchive`

Unarchive a project (Organization administrators only)

### `key`

Project key

Value: `KEY`

### `--force`

Bypass revision conflict protection (If\-Match: *)

Choices: `true`, `false`

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
