# `hamstik work link add`

Link this work item to another

### `key`

Work item key

Value: `KEY`

### `--target-key`

Target work item key (e.g. HAM\-43)

### `--target-id`

Target work item id (UUID)

### `--relation`

Relation kind

Choices: `blocks`, `blocked_by`, `relates`

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
