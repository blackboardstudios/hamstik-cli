# `hamstik project list`

List projects in the organization

### `--archived`

List only archived projects (true) or only unarchived (false); when omitted, unarchived projects are listed. Listing both states in one result requires separate queries

Choices: `true`, `false`

### `--limit`

Maximum items per page (endpoint maximum is 100 or 200)

### `--cursor`

Opaque continuation cursor

### `--all`

Follow all pages

Choices: `true`, `false`


Supports: `--json`, `--no-input`
