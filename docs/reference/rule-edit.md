# `hamstik rule edit`

Update an automation rule

### `rule_id`

Automation rule id

Value: `RULE_ID`

### `--body-file`

Read the JSON request body from this file; `\-` reads stdin

### `--field`

Structured JSON field as `key=value`; repeatable

### `--if-match`

Current rule ETag

### `--idempotency-key`

Idempotency key override


Supports: `--json`, `--no-input`
