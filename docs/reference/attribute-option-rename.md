# `hamstik attribute option rename`

Rename an option's display label without changing its key

### `attribute_key`

Stable Attribute key

Value: `ATTRIBUTE_KEY`

### `option_key`

Stable option key

Value: `OPTION_KEY`

### `--label`

New display label

### `--reason`

Optional audit reason

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
