# `hamstik sprint create`

Create a sprint

### `--name`

Sprint name

### `--start-date`

Planned start date (RFC 3339)

### `--end-date`

Planned end date (RFC 3339)

### `--goal`

Sprint goal

### `--target-points`

Target story\-point total

### `--project`

Project key (overrides context)

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
