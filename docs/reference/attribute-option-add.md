# `hamstik attribute option add`

Add an option to a select definition

### `attribute_key`

Stable Attribute key

Value: `ATTRIBUTE_KEY`

### `--key`

Stable option key (immutable after creation)

### `--label`

Display label

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
