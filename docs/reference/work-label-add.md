# `hamstik work label add`

Attach a label to a work item

### `key`

Work item key

Value: `KEY`

### `--label`

Label id (UUID) or label name

### `--force`

Bypass revision conflict protection (If\-Match: *)

Choices: `true`, `false`

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
