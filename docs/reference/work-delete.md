# `hamstik work delete`

Soft-delete a work item (Organization owners only)

### `key`

Work item key

Value: `KEY`

### `--cascade`

Also soft\-delete the entire descendant tree

Choices: `true`, `false`

### `--force`

Bypass revision conflict protection (If\-Match: *)

Choices: `true`, `false`

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
