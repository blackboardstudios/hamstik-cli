# `hamstik work comment edit`

Edit your own comment

### `key`

Work item key

Value: `KEY`

### `comment_id`

Comment id (UUID)

Value: `COMMENT_ID`

### `--body`

Replacement body

### `--body-file`

Replacement body source (path, or \- for stdin)

### `--body-editor`

Author the body in $VISUAL/$EDITOR instead of passing text

Choices: `true`, `false`

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
