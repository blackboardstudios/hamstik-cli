# `hamstik sprint unarchive`

Unarchive a sprint

### `id`

Sprint id (UUID)

Value: `ID`

### `--project`

Project key (overrides context)

### `--force`

Bypass revision conflict protection (If\-Match: *)

Choices: `true`, `false`

### `--idempotency-key`

Explicit idempotency key


Supports: `--json`, `--no-input`
