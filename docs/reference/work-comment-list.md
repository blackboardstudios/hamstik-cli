# `hamstik work comment list`

List comments on a work item

### `key`

Work item key

Value: `KEY`

### `--exclude-deleted`

Hide soft\-deleted comments instead of rendering `(deleted)` placeholders

Choices: `true`, `false`

### `--limit`

Maximum items per page (endpoint maximum is 100 or 200)

### `--cursor`

Opaque continuation cursor

### `--all`

Follow all pages

Choices: `true`, `false`


Supports: `--json`, `--no-input`
