# `hamstik org members`

List active members of an organization

### `slug`

Organization slug

Value: `SLUG`

### `--search`

Literal substring filter over name or username

### `--limit`

Maximum items per page (endpoint maximum is 100 or 200)

### `--cursor`

Opaque continuation cursor

### `--all`

Follow all pages

Choices: `true`, `false`


Supports: `--json`, `--no-input`
