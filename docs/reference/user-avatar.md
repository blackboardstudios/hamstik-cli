# `hamstik user avatar`

Download a user's avatar

### `public_id`

The user's public ID (usr_...)

Value: `PUBLIC_ID`

### ``-o`, --output`

Output path (defaults to the public ID with a content\-type derived extension)

### `--avatar-version`

Opaque avatar version cache selector

### `--format`

Opaque avatar format selector

### `--revision`

Opaque avatar revision cache selector


Supports: `--json`, `--no-input`
